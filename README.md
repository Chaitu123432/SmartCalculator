# SmartCalculator

## About

SmartCalculator is a Java-based calculator application developed as part of
the Pre-Joining Program.

The calculator provides a command-line interface for performing mathematical
operations such as addition, subtraction, multiplication, division, modulo,
square root, and percentage calculations. The project also demonstrates
object-oriented programming, interfaces, inheritance, polymorphism, input
validation, and exception handling.

A static HTML and CSS calculator interface has also been added as part of the
web development phase.
