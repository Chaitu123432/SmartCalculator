# Web Calculator Reflection

## CLI vs Web Interface

The CLI calculator takes input through the Java `Scanner`, where the user types
the first number, operator, and second number directly into the terminal. The
program validates the input and then creates the appropriate operation object
to calculate the result. The web calculator collects input through a graphical
interface containing a display and buttons, making the interaction more visual
and user-friendly. Unlike the CLI version, the current web interface is only a
static HTML and CSS design, so the buttons do not perform calculations.

## Where JavaScript Is Needed

JavaScript would be needed to handle button clicks, update the calculator
display, perform calculations, and show the results to the user.
